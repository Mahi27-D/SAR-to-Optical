# Real Data Pilot Validation Guide

This document outlines the requirements and process for executing the Phase 0 real-data pilot validation on a genuine subset of the SEN12MS-CR-TS dataset.

## Current Status
- **A. Already completed synthetic validation:** The strict causal indexing logic (N=3 and N=4) and causality assertions (`history_timestamp < target_timestamp`) have been successfully unit-tested on synthetic directories. This proves the logic is sound but does not constitute an experimental result.
- **B. Code prepared for real-data validation:** The script `run_real_pilot.py` has been created. It uses `tifffile` (since `rasterio` DLLs are blocked) to parse genuine `.tif` files, verifies actual image dimensions and bands, explicitly extracts bands B02, B03, B04, and B08, searches for official cloud masks instead of using brightness heuristics, pairs S1 and S2 based on precise metadata, and enforces strict causal logic assertions.
- **C. What remains impossible to verify until genuine SEN12MS-CR-TS files are available:** We cannot verify actual cloud-mask coverage values, genuine S1/S2 acquisition time differences, dataset-specific anomalies, or provide real experimental sequence counts (since the smallest official test region `multi_s1_asiaWest_test` + `multi_s2_asiaWest_test` is ~24 GB, which is impractical to download dynamically in this session).

## Requirements for the Pilot

To execute the real-data pilot, you must provide a genuine subset (even just a single region/patch folder) of the SEN12MS-CR-TS dataset. The subset must include:
1. **Real `.tif` files:** Actual Sentinel-1 and Sentinel-2 data from the dataset.
2. **Metadata file:** The `timestamps.json` or corresponding mapping file used to determine exact S1/S2 acquisition times.
3. **Official Cloud Masks (optional but recommended):** Pre-computed `_cloudmask.tif` files generated by `s2cloudless` as expected by the official baseline. If absent, the script will warn that the official s2cloudless integration is required.

## Execution

Once the data is mounted or downloaded to the workspace, execute the following command:

```bash
python run_real_pilot.py --data_root <path_to_real_data> --n_history 3
```

### Safety Mechanisms
- The script strictly checks for actual `.tif` files. If none are found, it immediately halts with: `"No real SEN12MS-CR-TS data found. Synthetic validation is not real-data validation."`
- Fake data generation is completely disabled in this script.
- Assertions strictly enforce that `history_timestamp < target_timestamp` for every single sample.
